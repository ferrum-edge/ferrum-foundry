# Ferrum Foundry v0.5.7 (candidate)

> **Candidate notes.** Foundry v0.5.7 is an unreleased candidate pairing with
> published Ferrum Edge v0.9.21. Hosted qualification and Foundry publication
> are pending. The latest published pairing remains Foundry v0.5.6 / Edge
> v0.9.20 in the [immutable v0.5.6 record](v0.5.6.compatibility.json).

This candidate moves the development and CI pin from Ferrum Edge v0.9.20 to
published v0.9.21, syncs Foundry's plugin sensitivity table across all 16
updated plugins (including the TLS-source, destination-path, and Redis rules),
and re-reviews the guided plugin schemas and server-owned subset traffic-policy
fields against the v0.9.21 OpenAPI specification.

The pairing depends on ferrum-edge#5661 resource ETag/If-Match handling,
ferrum-edge#5726 proxy-scoped plugin configuration filtering, and
ferrum-edge#6744, the `expected_proxy_ids` association precondition that

Binary hashes, OpenAPI identity and registry verification limits are recorded
in [compatibility](../compatibility.md#the-ci-pin); this pin claims no byte
comparison of the image's binaries with the release assets.

### Edge v0.9.21 pairing

- **Pin.** Starter, development command and current record move to the
  published Edge v0.9.21 digest. Package and lockfile root versions move to
  0.5.7.
- **Sensitivity projection (#728).** `PLUGIN_SENSITIVITY` and
  `PLUGIN_SENSITIVITY_SOURCE` sync to Edge v0.9.21 (`f9915358`): 16 plugins
  gain rules (`request_termination`, `transaction_debugger`,
  `ai_semantic_firewall`, `waf`, `openapi_validator`, `ai_tool_governor`,
  `mcp_gateway`, `opa`, `mesh_route_dispatch`, `request_mirror`, `mtls_auth`,
  `soap_ws_security`, `udp_logging`, `mesh_authz`, plus `redis_url` on
  `jwks_auth`, `hmac_auth`, and `soap_ws_security`). Pre-save placeholder
  checks and failed-write redaction now classify `endpoint-path`,
  `certificate`, and `private-key` sites directly from the pinned table.
- **Guided schemas and subset policy.** Guided plugin schema provenance
  (`PLUGIN_SCHEMA_SPEC.ref` and the `RateLimitingConfig` /
  `RateLimitingRuleConfig` digests) and `SUBSET_TRAFFIC_POLICY_SOURCE` move to
  `f9915358` after re-review; `KeyAuthConfig`, `CorsConfig`,
  `PrometheusMetricsConfig`, and `SubsetTrafficPolicy` are unchanged.
- **Contracts (#723).** Vendored contracts move to `contracts-edge-0.9.21`
  (`92d8da5b`, 37 scoped files): Edge v0.9.21 retains the same 82 built-in
  plugins, priorities, stream protocol matrix, and `provisioned-by`
  attribution while binding vocabulary provenance to Edge v0.9.21 (`f9915358`)
  and bringing the `ferrum-contracts#74`/`#82` `service-manifest` v1 schema
  rules and all 31 shared manifest fixtures (5 valid, 26 invalid).
